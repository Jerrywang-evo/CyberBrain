    Kimi API 配置（仅存本地浏览器）

    密钥仅保存在本机 localStorage，不会写入项目导出文件。

    控制回答随机程度：越大越发散。部分 Kimi 模型（如 kimi-k2.6）仅允许填 1，其他值会报错。

    DeepSeek API 配置（仅存本地浏览器）

    在 platform.deepseek.com 创建；密钥仅存本机，不会写入导出文件。

    控制随机程度：0～0.5 更稳定、适合严谨总结；1 为常用默认；1～2 更活泼。与 Kimi 规则不同，可按需调节（一般 0～2）。
