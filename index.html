    🎨 界面皮肤

    切换 Earth-Online 的视觉风格。皮肤会写入 JSON 备份与 GitHub 同步（preferences.uiSkin），并在各设备导入后恢复。

    风格灵感来自经典游戏美学，仅作 UI 主题致敬，与官方无关。

    🗺️ 大陆管理

    每块大陆是一处可探索的地图区域，拥有独立剧情。主线与支线任务线都归属某块大陆。新建大陆时可由 AI 生成背景故事。

    新建大陆后，在列表中点击「✨ AI 生成/重新生成」补充剧情（写入 JSON）。

    GitHub 同步

    将项目数据保存到 GitHub 仓库中的 JSON 文件，Mac / iPhone 等多端打开同一 Pages 地址即可共享数据（需配置 Token）。

    在 GitHub → Settings → Developer settings → Personal access tokens 创建，勾选 repo 权限。仅保存在本机浏览器。

    ✨ 模糊录入

    输入一段话，AI 会判断应创建大陆·地图·任务、大陆支线，还是日常记录。解析结果可编辑后再确认。

    AI 完成总结

    根据所选时间段与标签汇总已完成任务，按任务分段生成工作总结（每项一段，基于条目信息，不编造）。日期按 6:00～次日 6:00 为一天统计。

    选择条件后点击「生成总结」
    Kimi API 配置（仅存本地浏览器）

    密钥仅保存在本机 localStorage，不会写入项目导出文件。

    控制回答随机程度：越大越发散。部分 Kimi 模型（如 kimi-k2.6）仅允许填 1，其他值会报错。

    DeepSeek API 配置（仅存本地浏览器）

    在 platform.deepseek.com 创建；密钥仅存本机，不会写入导出文件。

    控制随机程度：0～0.5 更稳定、适合严谨总结；1 为常用默认；1～2 更活泼。与 Kimi 规则不同，可按需调节（一般 0～2）。
